# Транспортные знаки опасности — комплект для GHS-экосистемы

Собрано 06.08.2026. Всё в векторе, всё public domain, всё сверено с первоисточником.

```
adr/          29 знаков ADR / UN — без надписей, для панели ADR
dot/          62 знака 49 CFR — с надписями, для панели 49 CFR
_source-pd/   исходники как скачаны, ничего не трогали
```

---

## 1. ⚠⚠ Два комплекта, а не один. Это не дубликат

`§ 172.419` называется **FLAMMABLE LIQUID label**, `§ 172.442` — **CORROSIVE label**:
у США на знаке стоит слово, у ADR — нет. Один и тот же UN-номер в Европе и в
Штатах маркируется **разными картинками**.

Поэтому в панели ADR ставится файл из `adr/`, в панели 49 CFR — из `dot/`.
Это прямое продолжение правила раздела `/un/`: **юрисдикции не сливаются**.

## 2. ⚠ Пунктирная рамка снята — она не часть знака

**49 CFR 172.407(b)(2)** дословно:

> The dotted line border shown on each label is not part of the label
> specification, except when used as an alternative for the solid line outer
> border to meet the requirements of § 172.406(d).

ADR говорит то же в примечании к 5.2.2.1. Рамка на образцах — пояснение
«здесь край», а не элемент знака.

Следствие: у белых знаков (2.3, 6.1, 6.2, 7A, 7E, 8, 9, 9A) после снятия рамки
**внешнего контура нет вовсе** — так и задумано регламентом. Границу должен
давать фон страницы: знак ставится на слегка затемнённую подложку.

⚠ На трёх файлах рамка осталась: **adr-4.1, adr-4.2, dot-4.1**. Там она нарисована
не обводкой, а отдельными фигурами, и автоматическая проверка отказалась их
трогать, чтобы не задеть пламя и цифру. Снимать вручную.

## 3. Что сделано с каждым файлом

1. Найдена и снята пунктирная рамка — **проверкой, а не на глаз**: элемент
   удаляется, картинка перерисовывается, и разница обязана быть тонким кольцом
   по самому краю из многих несвязных кусков, ни один из которых не крупнее
   штриха. Иначе элемент возвращается на место.
2. Живой текст переведён в кривые. Иначе цифра класса поехала бы на машине без
   Arial или Verdana — восемь исходников набирали её шрифтом, а не контуром.
3. `viewBox` поджат вплотную к ромбу и сделан квадратным, `width`/`height`
   убраны: знак тянется по контейнеру.
4. svgo. **2 102 КБ → 1 120 КБ.**
5. В первой строке каждого файла — источник и лицензия.

⚠ **Сравнение по цвету, а не по прозрачности.** Первая версия проверки считала
краску по альфа-каналу и пропустила потерю: чёрный контур поверх белой заливки
прозрачности не меняет. Знак 4.1 при этом остался одними красными полосами —
без пламени, контура и цифры. Проверка переписана на сравнение цвета, и добавлен
откат: если ядро знака изменилось больше чем на 3 %, вся правка отменяется и
файл берётся исходным.

## 6. ⚠ Класс 1 у ADR печатается с заполнителем

На образце ADR стоит `*` вместо буквы группы совместимости, у США —
`** Replace with division number and compatibility group letter`.
То есть файлы `adr/adr-1.1…1.6` — это **основа**, а букву группы (`D` в `1.1D`)
подставляет компонент. Отдельных 34 картинок для ADR не нужно и не бывает.

У 49 CFR наоборот: в `dot/` лежат готовые 34 файла с уже впечатанным кодом.

## Класс 1 ADR: звёздочка и буква группы совместимости

В файлах `adr-1.1.svg` … `adr-1.6.svg` на месте буквы группы совместимости стоит
`*` — так напечатан сам образец в ADR 5.2.2.2.2. Файлы **не правились**: букву
рисует поверх звёздочки компонент `TransportLabel.astro`, плашкой в цвет фона
знака `#fc7e0c`.

Координата центра звёздочки измерена `getBoundingClientRect` по всем шести
файлам и во всех совпала:

```
центр по горизонтали  0.497 ширины знака
центр по вертикали    0.722 высоты знака
размер                ~0.045
свободная полоса      0.661 (низ цифры подразделения) … 0.776 (верх цифры класса)
```

Если комплект когда-нибудь заменят на другой источник, эти числа надо перемерить,
а не переносить.
